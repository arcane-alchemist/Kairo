---
name: global-ui-consistency
description: Keep Kairo component styling aligned with the existing frontend/styles.css tokens when editing layouts or controls.
---

Reuse Kairo’s existing lavender, ink, paper and accent tokens, DM Sans body text and Outfit headings. Use shared spacing, text, radius and touch-target variables for new product styles. Prefer the nearest existing token to one-off values. Keep semantic status colors readable using existing palette roles.

Compare tables, forms, cards, gallery, organizer and admin screens for consistent density. Keep responsive grids shrinkable with minmax(0,1fr), wrap long addresses and place wide data tables inside their own scroll regions. Preserve vendor Anatomy geometry and its shading tokens. Breakpoints and geometry dimensions may remain explicit where they describe layout behavior.
